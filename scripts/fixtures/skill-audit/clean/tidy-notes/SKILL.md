# Заметки встреч

1. Прочитать заметки пользователя целиком.
2. Выделить решения, задачи (кто, что, к какому сроку) и открытые вопросы.
3. Вернуть Markdown по образцу из [reference.md](reference.md).

Ничего не отправлять и не сохранять вне папки пользователя.
