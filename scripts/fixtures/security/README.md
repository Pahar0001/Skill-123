# Стенды для `security.mjs --selftest`

Два маленьких сайта и временный репозиторий, каждый с ожиданиями на каждый пункт
проверки. Страницы лежат файлами (`vuln/index.html`, `clean/index.html`), а
поведение, которого статикой не выразить (заголовки ответа, отдача `/.env`, ответ
`401` у API, кука сессии), задаёт сам selftest в `security.mjs` — так же, как
`fixtures/perf` держит страницы файлами, а поведение сервера — в скрипте.

## `vuln/` — сайт с нарочными дырами (ждём FAIL/WARN)

- `/.env`, `/server.js`, `/dump.sql` отдаются с сервера — **FAIL** «служебные файлы».
- `/api/admin/venues` без входа возвращает данные (JSON) — **FAIL** «админка/API без входа».
- `/admin` открывает панель без формы входа — **WARN** «проверить глазами».
- форма `#bad` методом `get` с полями телефон и имя — **FAIL** «форма GET с личными данными».
- ключ `AKIA…EXAMPLE` в инлайн-скрипте — **FAIL** «секреты в коде страницы».
- `https://mc.yandex.ru` — **WARN** «счётчики и реклама»; `https://ads.example.net` в iframe — **WARN** «чужие фреймы».
- нет заголовков безопасности (CSP, nosniff, X-Frame-Options, Referrer-Policy) — **WARN** по каждому.
- итог — **FAIL**. Значения секретов в выводе и в JSON замаскированы.

## `clean/` — сайт без дыр (ждём OK)

- `/.env`, `/server.js` и прочее — `404`, тело = странице 404 → **OK** «служебные файлы».
- `/api/admin/venues` → `401` → **OK**; `/admin` — страница входа с полем пароля → **OK**.
- форма `#ok` методом `post` → **OK**.
- заголовки CSP (`default-src 'self'`, без `unsafe-inline`), `nosniff`, `X-Frame-Options`,
  `Referrer-Policy`, `Permissions-Policy` — **OK** по каждому.
- кука `sid` с `HttpOnly` и `SameSite` (сервер на http-локали, `Secure` не требуется) — **OK**.
- итог — **OK**, ни одного FAIL.

## Временный репозиторий (в selftest, в `--out`)

git-репозиторий с секретом в первом коммите (позже убран), рабочим `.env` под git и
исправленным кодом. Ждём: `.env отслеживается git` — **FAIL**, секрет в `.env` — **FAIL**,
история просмотрена (свой поиск или gitleaks). Значения замаскированы. gitleaks для
детерминизма selftest отключается переменной `RW_SEC_NO_GITLEAKS`.
