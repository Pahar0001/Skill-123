# Реестр инструментов

Ревизия при запуске — обязательный первый шаг: состав меняется от машины к
машине и от сессии к сессии (MCP-серверы подключаются, кредиты кончаются).
Результат записать в `<папка прогона>/tools.md` — коротко: есть / нет / чем заменено.

## Чек-лист ревизии

1. Скрипты: `puppeteer-core`, `sharp`, `ffmpeg-static` ищутся в `SITE_REWORK_PROJECT`, текущей папке и `~/.claude/site-rework/node_modules`; путь к браузеру — `lib.mjs` найдёт сам (`CHROME_PATH`, для других — `FIREFOX_PATH`, `EDGE_PATH`); браузер пользователя по умолчанию — первая строка `runtime.mjs` / `shots.mjs`.
2. Браузерные MCP: `ToolSearch "select:mcp__chrome-devtools__new_page"` и
   `"select:mcp__playwright__browser_navigate"` — если схема пришла, сервер жив.
3. Скиллы рядом: `~/.claude/skills/design-reference` (снятие дизайн-системы),
   проектные скиллы вроде `predrelease` (проверки перед коммитом в конкретном репозитории).
4. Картинки и 3D: Higgsfield — `balance` (кредиты); Figma — `whoami`.
   Серверы, которым нужна авторизация, в сессии не включить — записать как недоступные.
5. Документация: Context7 (`resolve-library-id` → `query-docs`) для Three.js, GSAP, Swiper и прочих.
6. Ограничения среды: ОС, оболочка, лимиты сервера (например, 5 запросов в минуту с адреса).

## Код

`Read`, `Edit`, `Write`, `Glob`, `Grep`, `Bash`/`PowerShell`, `git`. Большие
файлы писать `Write`, не heredoc через Bash: на Windows длинная команда не
проходит в аргумент. Коммит и пуш — только по просьбе; в репозиториях с
проектным скиллом проверок (`predrelease`) — сначала он.

## Картинки

Порядок всегда один: **переиспользовать существующее → законные бесплатные
источники (`media.mjs`) → отредактировать → сгенерировать**. Подробно —
`reference/engines.md` → «Картинки и видео». Каждый новый кадр открыть глазами: стоковые фотографии
регулярно противоречат подписям (чужие телефоны, доллары в ценнике,
не та кухня).

|---|---|---|

## 3D и WebGL

| подход | когда | проверка |
|---|---|---|
| Three.js с CDN (`cdnjs`, `jsdelivr`), процедурная геометрия, шейдер | только когда 3D нужно: предмет заказчика или объект из языка донора; по умолчанию 3D нет, частицы «для атмосферы» — дефолт из каталога | `runtime.mjs --canvas` (буфер не пуст, кадр меняется, кадры/с), снимок глазами, `perf.mjs` на телефоне, `--viewport mobile` |
| готовая модель GLB/GLTF пользователя | показать продукт | то же + вес модели в бюджете |
| Higgsfield `generate_3d` (`image_to_3d`, `multi_image_to_3d`, `sam_3_3d`), `scene_builder_3d_*` | модель из фото товара, когда своей нет | кредиты; согласие пользователя |

3D не добавлять там, где оно не улучшает историю, бренд, подачу продукта
или иерархию. Всегда: ленивая инициализация по видимости, `devicePixelRatio`
не выше 2, остановка вне экрана, постер-запас без WebGL, отключение при
`prefers-reduced-motion`.

## Движение

Порядок — `reference/motion.md`: снять движение донора `motion.mjs`, перенести каждое с его числами
(рецепты там же), добавить своё из товара и 1–2 идеи из банка (`ideas.mjs pick`), сверить
`motion.mjs compare`. Техника: CSS-переходы и ключевые кадры → Web Animations API → GSAP (с CDN) только
для последовательностей и привязки к прокрутке, которые CSS не тянет →
Lottie только с готовыми файлами. Проверка: `runtime.mjs <url> --motion --scroll --hover "<селектор>"`
(все правила :hover разом — `--hover-all`), `motion.mjs compare`,
снимки в фазах, `perf.mjs` (кадры/с при прокрутке).

## Ограничения среды (эта машина)

- Windows 11, Git Bash и PowerShell; Node 22; `puppeteer-core`, `sharp` и `ffmpeg-static` стоят в `~/.claude/site-rework/node_modules` — скрипты запускаются из любой папки.
- Edge в безголовом режиме завершается молча — Chrome стоит первым в поиске.
- Браузер пользователя по умолчанию — Firefox (реестр UserChoice → FirefoxURL): все проверки в Chrome, а перед сдачей — дымовая проверка в Firefox: `runtime.mjs` и `shots.mjs` с `--browser firefox` (WebDriver BiDi, puppeteer-core ≥ 23). Установка пакетов прямо в домашней папке (здесь — случайный puppeteer-core 23.11) берётся последней: require из любой папки под домашней находил её раньше `~/.claude/site-rework` (25.5), и скрипты из папки скилла шли на другой версии. Карта импортов раньше любого `modulepreload` — иначе Firefox её отбрасывает (VN3D, 24.09).
- Кредиты Higgsfield меняются — смотреть `balance` при каждой ревизии и записывать в `tools.md` прогона, а не сюда.
- Студийный сервер (`D:/ssi/sites`): 5 запросов в минуту с адреса на API — два прогона проверок подряд дают ложные 429.
