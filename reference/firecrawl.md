# Firecrawl — сбор данных для сайта

Firecrawl — облачный сервис: сам открывает чужие страницы и отдаёт их текст, список адресов сайта и
фирменный стиль. В скилле он только **собирает данные**. Скрипт — `scripts/firecrawl.mjs` (запросы к
Firecrawl напрямую, без CLI), полный путь — `node ~/.claude/skills/site-rework/scripts/firecrawl.mjs`.
Ключ — `FIRECRAWL_API_KEY` в `~/.claude/site-rework/.env`; нет ключа — команда пропускается строкой
`INFO пропуск: нет FIRECRAWL_API_KEY`, прогон идёт дальше без неё.

## Когда брать

| задача | команда | кредитов |
|---|---|---|
| разведка донора: увидеть все типы страниц | `firecrawl.mjs map <донор> --run <папка>` | 1 |
| «контента нет — сделай сам»: факты о деле со ссылками | `firecrawl.mjs facts --run <папка> --about "<дело, город>"` | 2 + по 1 за источник (5 источников — 7) |
| подбор донора: стиль трёх кандидатов | `firecrawl.mjs scrape <кандидат> --run <папка> --formats branding` на каждого | по 1 |
| разбор тона: текст страницы | `firecrawl.mjs scrape <адрес> --run <папка> --formats markdown` | 1 |
| страницы по теме с выдержками | `firecrawl.mjs search "<запрос>" --run <папка>` | 2 за каждые 10 результатов |
| остаток кредитов | `firecrawl.mjs status --run <папка>` | 0 |

**map.** Адреса сайта из его карты (sitemap.xml) и поиска — без захода на страницы — разложены по
типам по шаблону адреса, как в `discover.mjs`: `/menu`, `/product/*`, `/blog/*`, `/contacts`. Итог —
`<папка>/firecrawl/map-<сайт>.md`: типы с образцом и готовая строка `--pages` «по странице каждого
типа» для `motion.mjs` (и путями — для `copy.mjs` и `shots.mjs`). Разведка донора проходит каждый тип
хотя бы одной страницей: карта находит и те, на которые главная не ссылается.

**facts.** Ищет по делу и городу, читает до 5 источников и выписывает цены, сроки, проценты, числа и
условия — те же заявления, что сверяет `copy.mjs`. x.com, видео и соцсети, PDF, второй адрес того же
сайта пропускает; источник, который не прочитался, заменяет следующим. Итог —
`<папка>/copy/facts-candidates.json` в формате facts.json (`fact`, `what`, `source` — адрес и дата
чтения) и `<папка>/firecrawl/facts-<дело>.md` — таблица для глаз.

Это **кандидаты, не факты.** В `copy/facts.json` переносить только проверенное глазами: открыть
источник, убедиться, что факт про это дело и этот город и ещё верен. Годится верное для дела вообще —
обычные сроки, условия, разброс цен по городу. Цена или часы одного заведения — ориентир для
правдоподобного примера, а не цена клиента: такой пример на сайте — в список для владельца
(`copy/invented.json`).

**scrape.** Текст страницы — основное содержимое без шапки и подвала — в `scrape-<адрес>.md`; стиль
(тема, цвета, шрифты, логотип) — в `scrape-<адрес>.json` и строкой в выводе. Стиль — подсказка, чтобы
выбрать из трёх кандидатов, а не замер: числа донора снимают `discover.mjs` и `extract.mjs`
(design-reference), кириллицу шрифтов проверяет `cyrillic-check.mjs`. Текст страницы, которую скрипт
сайта перестраивает, Firecrawl иногда склеивает без пробелов (30.09 так вышло у example.com) — вывод
предупреждает «текст слипся», facts такой источник заменяет следующим. Точный текст донора снимает
`copy.mjs snapshot`.

## Когда нет

- **Замеры** — шрифты, отступы, сетка, движение, скорость: только свои скрипты с живой страницы
  (discover, typeset, motion, perf, design-reference).
- **localhost, 127.0.0.1, частные сети, file://** — облако не видит эту машину; скрипт откажет (код 2).
- **Фото и видео** — `media.mjs` (законные источники, лицензии), не Firecrawl.
- **Файлы клиента** — ТЗ, прайсы, договоры, голосовые — в облако не отправляем: читать на этой машине
  (`Read`, pdftotext, whisper).
- **x.com и twitter.com** — у Firecrawl отдельная цена; **PDF** — кредит за каждую страницу файла.
  Скрипт их не читает.
- **Страницы за входом**, корзина, формы — не читаем.

## Бюджет

- Тариф бесплатный: 1000 кредитов в месяц, 2 задачи одновременно, 10 запросов в минуту на map,
  scrape и search.
- На один сайт — **до 50 кредитов**: это предел `--budget` по умолчанию. Учёт — по записи на вызов в
  `<папка>/firecrawl/budget.json`; вызов, который не влезает, не уходит (код 2). Больше — только
  осознанно, `--budget N`.
- Повтор того же вызова — из кэша (`<папка>/firecrawl/cache/`), бесплатно и даже без ключа; `--fresh` —
  спросить заново.
- Остаток на тарифе — команда status (или CLI Firecrawl, или firecrawl.dev/app). Смотреть при ревизии
  инструментов и записывать в `tools.md` прогона.
- Обычный расход на сайт: карта донора 1 + факты 7 + стиль трёх кандидатов 3 = 11.

## Цена (docs.firecrawl.dev/billing, 30.09.2026)

| что | кредитов |
|---|---|
| map | 1 за вызов при любом числе адресов |
| scrape: текст и стиль | 1 за страницу; страница с ошибкой 404 — тоже 1 (документ вернулся) |
| search | 2 за каждые 10 результатов (11 результатов — 4) |
| facts | поиск 2 + по 1 за прочитанный источник |
| status | 0 |
| сайт не ответил, документа нет | 0 |
| JSON и вопросы к странице | +4 за страницу — скрипт их не делает |
| PDF | +1 за каждую страницу файла — скрипт PDF не читает |
| обход раздела (crawl) | 1 за каждую страницу — скрипт не делает |

## Навыки Firecrawl

В Claude Code стоят и навыки Firecrawl — `firecrawl`, `firecrawl-search`, `firecrawl-scrape`,
`firecrawl-map`, `firecrawl-crawl`, `firecrawl-download`, `firecrawl-agent` и другие (включён 21). Они
работают через CLI с того же счёта и **тратят те же кредиты**, но бюджет папки прогона их не видит, а
`crawl` и `download` берут по кредиту за каждую страницу — сотня страниц съедает два сайта. В работе
над сайтом — скрипт; навык — только для того, чего скрипт не умеет, с ценой заранее и строкой в
`tools.md` прогона. Выключенные как дубли (`firecrawl-qa`, `firecrawl-interact`, `firecrawl-parse` и
другие) и чем они заменены — `reference/tool-registry.md`.
