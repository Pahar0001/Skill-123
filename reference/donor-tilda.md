# Донор на Tilda

Tilda у нас — **только донор**: снять язык, движение и фактуру Tilda-сайта, чтобы собрать свой сайт в
этом языке. Правок сайтов на Tilda и переноса сайтов с Tilda скилл не делает.

Сайт на Tilda узнаётся по `#allrecords.t-records` с `data-tilda-page-id`, блокам `.t-rec[data-record-type]`
и адресам `tildacdn.com` (discover пишет «платформа: Tilda»; в коде — `TILDA_FN` / `tildaInfo` из `lib.mjs`).
Язык такого донора лежит в атрибутах разметки — точнее, чем его можно замерить. **Где есть атрибут,
замеру не верить.**

## Порядок

1. Как обычно (`donor-mode.md` §1): discover, extract, texture, cliche, motion. По одному скрипту за раз:
   TLS у Tilda бывает медленным (6–20 с на рукопожатие), скрипты сами повторяют переход.
2. Сверху — карта Tilda:
   ```
   node ~/.claude/skills/site-rework/scripts/tilda.mjs <донор> --viewport desktop,mobile --out <папка>/donor
   node ~/.claude/skills/site-rework/scripts/tilda.mjs pages <донор> --out <папка>/donor
   ```
   → `donor/tilda/`:
   - `tilda-<экран>.md/json` — блоки с кодами, Zero Block по брейкпоинтам (zoom, кегли на экране),
     появления, пошаговая анимация шагами, параллакс, хуки окон и меню, ленивые картинки;
   - `tilda-motion-<экран>.json` — движение в схеме motion.json, у каждого пункта `plays` (играет ли у донора
     на этом экране) и `screens` (все экраны / только ≥ 1200 / только < 1200 / нигде);
   - `tilda-layout.json` — поля элементов Zero Block по брейкпоинтам (числа для сетки и ритма, не вёрстка);
   - `tilda-pages.json` — типы страниц по подписи блоков и готовая строка `--pages "home=/,tpl2=/…"` —
     её отдать discover (`--pages-shots`) и motion (`--pages`).
   Без браузера, за секунды: `tilda.mjs static <файл.html | адрес>` — та же карта из голого HTML для 1440 и 390
   (Zero Block, который скрипт Tilda дорисовывает после загрузки, в голом HTML неполон).
3. В `analysis.md` → «Донор» — строка платформы: коды блоков сверху вниз, брейкпоинты артбордов, `upscale`
   и zoom на 1440 и 390, выключены ли появления проектом (`data-blocks-animationoff`).

## Чему верить

| что | источник | почему не замер |
|---|---|---|
| кегли и размеры в Zero Block | extract (с 28.09.2026 — «extract 2026-09-28.2») и `tilda.mjs`: computed × zoom; поля `data-field-*` | при `upscale=window` Tilda масштабирует элементы CSS `zoom` = окно / брейкпоинт: у madeon.studio на 1440 zoom 1.2 — computed h1 40px, на экране 48px; на 390 — 390/320 = 1.219 |
| сетка | `.t-container` 1200 (содержимое 1160: 12 колонок по 60, зазор 40, `t-col_N` = 100·N − 40); в Zero — `container grid`: x = (ширина окна − 1200)/2 + left | первый «центрированный блок» на Tilda — колонка или элемент артборда |
| брейкпоинты | `data-artboard-screens` у каждого артборда | не всегда 320/480/640/960/1200: у madeon 320/640/960/1200/1920, у romashka 320/640/1200 |
| значение на экране N | поле `-res-N`, нет — ближайший больший брейкпоинт, нет — базовое (самый широкий экран) | так читает сама Tilda |
| появления | `data-animate-*` + умолчания Tilda (ниже) | motion ловит середину перехода и называет её прокруткой или параллаксом |
| пошаговая анимация (SBS) | `data-animate-sbs-*`, шаги `sbs-opts` | motion видит первый и последний кадр, петли при входе в экран путает с прокруткой |
| параллакс | `prx-s` → скорость → px на проход | замер даёт коэффициент на всю страницу, а смысл — «скорость × 100 px, пока элемент идёт через экран» |
| окна и меню | хуки `#popup:<имя>` → окно с `data-tooltip-hook`, `#menuopen` → шторка T450 | пара «ссылка → окно» точная, эвристика не нужна |
| типы страниц | подпись блоков (`tilda.mjs pages`) | адреса плоские: `/abuse`, `/choi` — не типы, а страницы одного шаблона (streetwearbrands: 66 адресов → 5 типов вместо 63) |
| ленивые картинки | `data-original`, `.t-bgimg.loaded` | `loading="lazy"` у Tilda нет, до прокрутки на месте фото — заглушки `…/-/resize/20x/` |

**Атрибут не значит, что играет.** Tilda выключает появления сама:
- `data-blocks-animationoff="yes"` у `#allrecords` — появлений нет нигде (пошаговая анимация играет);
- на ширине < 1200 — все появления, кроме элементов Zero Block с `data-animate-mobile="y"`; пошаговая анимация,
  параллакс и фиксация Zero Block без этого атрибута выключены, когда брейкпоинт артборда < 1200;
- блок с `t-screenmin-*` / `t-screenmax-*` на этом экране скрыт — его движения нет.
`tilda.mjs` пишет это в `plays`: по классам после прокрутки (`t-animate_started`, снятый `t-animate`, обёртка SBS,
`data-parallax-speed`), если скрипты Tilda на странице есть, иначе по этим правилам.

**Что Tilda выключает на телефоне, у нас на телефоне не делаем.** У донора там этого движения нет — повторять
нечего. Пустой инвентарь движения телефона на Tilda — правда, а не сбой. Своё движение на телефоне — только как
своё (банк идей, решение в `analysis.md`), не как «повтор донора».

## Движение Tilda → наши рецепты (`motion.md`)

- **Появление стандартного блока** → `reveal`:
  - из: прозрачность 0 и сдвиг 100 px (`fadeinup` — снизу, `fadeindown` — сверху, `fadeinleft` — справа,
    `fadeinright` — слева), `zoomin` ×0.9, `zoomout` ×1.2, `fade-in-blur` 12 px; `word-*` и `line-*` — по словам и строкам;
  - длительность: заголовок (`.t-title`) 1.2 с; текст, подзаголовок (`.t-descr`, `.t-subtitle`, `.t-text`, `.t-uptitle`)
    0.7 с; карточка (`.t-item`) 0.5 с; прочее 1 с; свои — `data-animate-duration` / `-delay` (в секундах), `-distance`, `-scale`;
  - кривая `cubic-bezier(.19,1,.22,1)`;
  - срабатывает, когда верх элемента входит в окно снизу (минус `trigger-offset`);
  - `chain` — ряды по очереди, +160 мс на ряд; `group` — элементы блока вместе.
- **Появление в Zero Block** → то же, свои `duration`, `delay`, `distance`, `scale` у каждого элемента.
  Задержки донора переносить как есть (`timing.delays` в `tilda-motion`), а не «по очереди +N». Сдвиг на экране — × zoom.
- **SBS `intoview` / `blockintoview`** → `@keyframes` (`keyframes` у пункта уже посчитаны):
  - offset шага = накопленная сумма `ti` / общая длительность; `ti: 0` у шага — скачок сразу;
  - `transform: translate(mx,my) rotate(ro) scale(sx,sy)`, `opacity: op`, `filter: blur(bl)`; `mx`, `my` — от начального места;
  - кривая отрезка — `ea` шага, к которому он ведёт: easeIn → ease-in, easeOut → ease-out, easeInOut → ease-in-out,
    bounceFin → cubic-bezier(0.34,1.61,0.7,1), свой `cubic-bezier(…)` — как есть, пусто или «0» → linear;
  - `dd` / `dt` — пауза перед шагом;
  - старт — класс при входе в экран (`blockintoview` — когда в окно входит блок); `loop` → `infinite`,
    `loopwithreverse` → `alternate`. Вид: петля (`loop`: пульс, вращение, мигание, парение) или многошаговый `reveal`
    (мигание в 5–7 шагов у madeon — не «прозрачность 0 → 1»).
- **SBS `scroll`** → `scroll-scrub`: отрезок начинается, когда верх элемента на `trg` окна (1 — низ, 0.5 — середина)
  плюс `trgofst`, и длится сумму `di` px прокрутки (× zoom). `fi` — элемент закреплён на шаге (`pin`).
  Проверено на zero.tilda.cc: лента 340 px на 500 px прокрутки = 0.68, край «верх блока 100% → 44%».
- **SBS `hover`** → `hover`: вперёд при наведении, назад при уходе (кроме `noreverse`). Триггер — `sbs-trgels`
  (id элементов того же артборда) или сам элемент. Типичное у клиентских сайтов (madeon):
  - два слоя текста кнопки меняются прозрачностью за 200 мс;
  - плюс поворачивается на 45° ease-in-out за 200 мс.
- **Параллакс `prx scroll`** → `parallax`: сдвиг = скорость × 100 px за проход элемента через экран (высота элемента +
  высота окна), скорость = round((prx-s − 100)/10). Без `prx-s` элемент стоит. Проверено: prx-s 115 → 200 px на
  446 + 900 px = 0.1486.
- **Мышь `prx mouse`** → `mouse-tilt`: `prx-dx`, `prx-dy` px; на сенсорных экранах < 1200 выключено.
- **Фиксация `data-animate-fix`** → `pin`: точка `fix` окна + `fix-trgofst`, отрезок `fix-dist` px.
- **Бегущая строка T1003, печать T635, аккордеон T668** — motion снимает их верно, брать его числа.
- **Окна T1093** — вид появления в `data-anim` (у madeon fadein), рядом `data-anim-timeout` (0.3); длительность
  и кривую окна сверять замером motion по клику. Содержимое окна — Zero Block из `data-popup-rec-ids`.

«Меньше движения» у Tilda нет. У нас оно обязательно (`motion.md` → общие правила).

## Не язык донора — не переносить

- Плашка «Made on Tilda» (`#tildacopy`, `.t-tildalabel`).
- Заглушка «Zero Block» за краем артборда и всё, что артборд обрезал на этом экране.
- Служебное (`TILDA_SERVICE` в `lib.mjs`): `.t-mbfix`, полоса загрузки T360 (`.t360__progress`) и проявление страницы
  `#allrecords` за 0.5 с, ссылка-пропуск.
- `transition: all` из CSS конструктора (`tilda-*.min.css`).
- Цвет-подложка ленивого фона `.t-bgimg` (под шумом у streetwearbrands — #FFF705).
- Шрифты проекта по умолчанию (Times New Roman / Arial в настройках), если их не видно на экране: смотреть
  загруженные (`document.fonts`, строка «шрифты проекта» в `tilda-*.md`) и снимки.
- **TildaSans — шрифт конструктора. Вне Tilda его не берём, пока лицензия не проверена.** Замену подобрать
  по снимкам и проверить кириллицу `cyrillic-check.mjs`.
- HTML-вставки T123 — не служебное: там бывает свой CSS/JS дизайнера (шум, курсор). Смотреть отдельно.

## Окна и меню

Окна и боковые меню Tilda открываются ссылками-хуками: `#popup:<имя>` → окно с `data-tooltip-hook="#popup:<имя>"`,
`#menuopen` → шторка T450/T451, закрытие — `#closepopup` или Escape. `tilda.mjs` выписывает пары «ссылка → окно»
(и окна без ссылки на странице). Меню, собранное в Zero Block, — это закреплённые элементы со ссылками-якорями:
на широком экране его может не быть в `nav` (streetwearbrands — плавающая пилюля внизу окна; extract находит его
ступенью «закреплённое меню (fixed) внизу окна»). Стандартные меню: T228, T456, T199, T966 — верхние; T450/T451 —
шторка; T280 — на весь экран; T975 — нижняя панель телефона.

## Проверка себя

- `motion.mjs compare` сверяет наш сайт с `tilda-motion-*.json` так же, как с motion.json донора; строки с
  `plays: false` в сверку не брать — у донора этого движения на экране нет.
- Кегли нашего сайта сверять с донорскими **после поправки на zoom**. Спецификация донора, снятая extract до
  2026-09-28.2 (строки «Платформа: Tilda» в `donor.md` нет), у upscale=window мельче экрана на коэффициент zoom —
  переснять, иначе verify «подтвердит» сайт на 20% мельче.
- discover, motion, clicks и cliche читают Tilda сами (с 28.09.2026, b2102c9): кегли × zoom, служебное и
  обрезанное артбордом вне языка, пункты движения из атрибутов, ложные «свои аккордеоны» (`div.t396__artboard`,
  `div.tn-molecule`, `footer.t-records`) отсечены, типы страниц — по подписи блоков. Протоколы, снятые до этого,
  сверять с `tilda/` по-старому.
- Сдвиги Zero Block в замере motion (не Tilda-пункты) при upscale=window занижены на zoom: transform в computed —
  в px элемента (romashka: −120 px в CSS, −144 px на экране).
