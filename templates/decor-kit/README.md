# decor-kit — детали для красоты

Общий набор приёмов для правила 6 навыка: на **каждом** сайте, в любом режиме (переработка, донор,
с нуля), — фон с характером, свои рисунки линией из мира дела, надписи-логотипы разделов, игра
шрифтов, предметы за краем, печать с фактами и движение, у каждого раздела — свой мотив.
Вынесен из «Эпицентра» (коммит `270cc16`, файлы `mamuka-decor.*`) без названий, шрифтов, цветов
и текстов того сайта.

Набор даёт **механику**: разметку, движение, доступность, «меньше движения», паузу вне экрана.
**Вид** у каждого сайта свой: шрифты, рисунки, слова, мотивы и цвета придумываются под дело и
донора — набор их не содержит. Всё, что в `demo.html` про пекарню, — пример, а не заготовка.

| Файл | Что в нём |
|---|---|
| `decor-kit.css` | неподвижная часть и движение: логотипы, рисунки, слои фона, печать, предмет за краем, табло, заливка автосмены, место под мотивы, «меньше движения» |
| `decor-kit.js` | ES-модуль без зависимостей: оживляет атрибуты `data-dk-*`, `window.decorKit` |
| `demo.html` | образец со всеми приёмами (вымышленная пекарня «Опара»), свой спрайт рисунков внутри |
| `demo-photo.svg` | рисованная заглушка вместо фото для шторки в демо |

Открыть демо: `node ~/.claude/skills/site-rework/scripts/serve.mjs ~/.claude/skills/site-rework/templates/decor-kit --port 4180`
→ `http://localhost:4180/demo.html`. Двойным щелчком (`file://`) Chrome модуль не грузит — страница
тогда показывает, как она выглядит без JS (всё читается, движения нет). `runtime.mjs` открывает
`file://` и с модулем: он запускает Chrome с разрешением на локальные файлы.

## Подключение — две строки

Скопировать `decor-kit.css` и `decor-kit.js` в папку сайта (не ссылаться на папку навыка):

```html
<link rel="stylesheet" href="/assets/decor-kit/decor-kit.css">
<script type="module" src="/assets/decor-kit/decor-kit.js"></script>
```

Модуль запускается сам после разбора страницы. Ручной запуск — `<html data-dk-manual>` и
`import { init } from '…/decor-kit.js'; init({ sprite: '/assets/img/decor.svg' })`.

**Спрайт своих рисунков** — вписать в начало `<body>` (работает везде, и с `file://`):

```html
<svg width="0" height="0" style="position:absolute" aria-hidden="true" focusable="false">
  <symbol id="loaf" viewBox="0 0 64 64"><path pathLength="1" d="…"/></symbol>
</svg>
…
<svg class="dk-draw" aria-hidden="true" focusable="false"><use href="#loaf"/></svg>
```

или отдельным файлом **с того же адреса**: `<use href="/assets/img/decor.svg#loaf">` и
`<html data-dk-sprite="/assets/img/decor.svg">` (россыпь и `draw()` собирают адрес из него).
`<use>` на файл с другого домена браузеры не рисуют. Файл спрайта — с меткой версии
(`decor.svg?v=<хэш>`), если его будут заменять под тем же именем.

**Первый экран и скорость.** Стили — в `<head>` обычной ссылкой: без них надписи-логотипы и
бледные слова первого экрана рисуются неправильно. Модуль отложен сам (`type="module"`) и первый
экран не прячет. На «Эпицентре» (30.09, телефон, fast3g) 11 КБ стилей декора блокирующей ссылкой
стоили главной +0.17 с LCP, всё после события `load` — +56 мс (в пределах разброса). Здесь стили —
19.5 КБ (6.1 КБ после gzip), скрипт — 41 КБ (13.8 КБ после gzip), по большей части комментарии.
Если первый экран тяжёлый и `perf.mjs` показывает рост LCP, модуль грузить после `load`:
`addEventListener('load', () => import('/assets/decor-kit/decor-kit.js'))` — до его прихода всё
видно, просто без движения.

## Переменные

Все — `--dk-*`; задаются там, где нужны: на `:root` — общее для сайта, на классе раздела — его голос,
в `style="…"` — место и размер одного элемента. Не заданные шрифт, вес и регистр наследуются от блока.

| где задавать | переменные |
|---|---|
| `:root` сайта — движение и линия | `--dk-line` (1.5px — толщина линии рисунков на экране); `--dk-ease-out`, `--dk-ease-move` (берут `--ease-out` и `--ease-in-out` сайта, если они заведены по `reference/motion.md`, иначе кривые Эмиля); `--dk-lines-dur`, `--dk-lines-step`, `--dk-draw-dur`, `--dk-curtain-dur`, `--dk-curtain-zoom`, `--dk-count-dur`, `--dk-count-step`, `--dk-words-dim`, `--dk-words-dur` |
| класс раздела — его голос | `--dk-logo-font`, `-weight`, `-style`, `-case`, `-track`, `-scale`, `-stretch`, `-lh`; `--dk-sign-size`, `--dk-sign-line`; `--dk-bgword-font` (по умолчанию — `--dk-logo-font` раздела), `-weight`, `-style`, `-case`, `-track`; `--dk-alt-font`, `-style`, `-weight`, `-scale`, `-color`, `-track`; `--dk-word-font`, `-weight`, `-case`, `-track`; `--dk-stamp-font`, `-weight`, `-case`, `-min`; `--dk-scatter-alpha`, `--dk-speck-alpha`; `--dk-seg`, `--dk-seg-h`, `--dk-seg-gap`, `--dk-seg-track`, `--dk-seg-fill` |
| `style="…"` элемента — место и размер | `--dk-s` (размер рисунка, px числом: `--dk-s: 96`; на самом рисунке или его классе — от родителя не наследуется), `--dk-box` (поле рисунка, если не 64 и спрайт не в странице), `--dk-delay`; `--dk-x`, `--dk-y`, `--dk-fs`, `--dk-rot`, `--dk-alpha` (бледное слово); `--dk-stamp-size`; `--dk-pop-top`, `-right`, `-bottom`, `-left`, `-rot`, `-size` |

## Как ведут себя приёмы

- **Прячется до появления только то, чего нет на экране** в момент разметки. Первый экран не ждёт
  анимаций; мотив, который виден при загрузке, не прячется и сам не играет — только наведением.
- **Без JS и при «меньше движения»** всё видно сразу в конечном виде: прятанье — только под классом
  `dk-armed`, который ставит скрипт. Включили «меньше движения» при открытой странице — `finish()`
  доводит всё до конца, автосмена останавливается.
- **Движение** — только `transform`, `opacity`, `clip-path`, `stroke-dashoffset`; вёрстка не
  сдвигается. Петель нет: мотивы играют раз при входе в экран и заново по наведению мыши (не чаще
  раза в 1.5 с, при касании — нет). Вне экрана анимации мотивов стоят (`.dk-off`), автосмена на паузе.
- **Строки и цитата** после движения снимают свои обёртки — дальше обычный текст (выделяется,
  копируется, переносится как был; неразрывные пробелы держат слова вместе).
- **Табло** пишет число через `toLocaleString('ru-RU')` (12500 → «12 500», 4.5 → «4,5»); для чтения
  с экрана — число целиком; после ленты снова обычный текст. Число — отдельным элементом, «+»,
  «₽» и подписи — рядом, не внутри. **Только подтверждённые числа** (`copy/facts.json`), придуманное
  — в `copy/invented.json`.
- **Автосмена**: конец заливки переключает слайд, поэтому пауза заливки — пауза смены. Пауза —
  наведение мыши, фокус внутри, блок вне экрана, скрытая вкладка, кнопка «Пауза» (набор добавляет
  её сам — WCAG 2.2.2). Выбор слайда человеком и «меньше движения» останавливают автосмену, «Дальше»
  запускает. Без JS видны все слайды списком. Свой слайдер сайта: слушать `dk:autoplay`
  (`detail: { index, prev, cause }`), слайды переключать самому; из кода — `autoplay.go(box, i)`,
  `autoplay.pause(box, true|false)`, `autoplay.stop(box)`.
- **Печать**: кегль на экране не меньше `--dk-stamp-min`, разрядка растягивает текст ровно по кругу
  (`letter-spacing`; `textLength` на `textPath` Firefox не понимает). Не влезло — предупреждение в
  консоли: короче текст или крупнее печать. Только настоящие факты дела (год, адрес, часы), и они
  же — обычным текстом на странице: печать — `aria-hidden`.
- **Россыпь** — у левого и правого краёв (или по всему полю), бледная, повёрнутая, с крапинками; на
  телефоне вдвое меньше и мельче; раскладка одна и та же при каждом заходе (`-seed` — другая).
  Ниже первого экрана рисуется линией при входе.
- **Слой фона** (`.dk-host` → `.dk-layer`) лежит под текстом, обрезан краем блока, мышь не ловит.
  `isolation` делает блок отдельным слоем наложения — выпадающее меню внутри не перекроет соседний блок.
- **Предмет за краем** на экране уже 720 px за боковой край не выходит, только за верх и низ.

## Мотив раздела — свой у каждого раздела

Набор ставит классы, вид задаёт сайт. Обычный вид без классов — он же конечный и он же без JS;
`.dk-set` — начало (без перехода), `.dk-play` — переход к обычному виду:

```html
<div class="motif-row dk-motif-host">
  <svg class="dk-draw m-steam" data-dk-motif viewBox="0 0 64 64" style="--dk-s: 112" aria-hidden="true" focusable="false">
    <path pathLength="1" d="…чашка…"/>
    <path class="wisp" pathLength="1" style="--dl: 0s" d="…пар снизу вверх…"/>
  </svg>
</div>
```

```css
.m-steam.dk-set .wisp  { stroke-dasharray: 1 1.01; stroke-dashoffset: 1.005; opacity: 0; transform: translateY(5px); }
.m-steam.dk-play .wisp { stroke-dasharray: 1 1.01; stroke-dashoffset: 0;
  transition: stroke-dashoffset 2s var(--dk-ease-move) var(--dl), opacity .9s ease var(--dl), transform 2.6s var(--dk-ease-out) var(--dl); }
```

Содержимое, которое удобнее построить скриптом (россыпь муки, столбики, волны), — `registerMotif`:

```js
import { registerMotif } from '/assets/decor-kit/decor-kit.js';
registerMotif('flour', (el, { rng }) => { const R = rng(9); el.innerHTML = `<svg …>…</svg>`; });
```

```html
<span class="flour" data-dk-motif="flour"></span>   <!-- размер — в CSS сайта: место занято сразу -->
```

Такой мотив без JS пуст — годится только для декора. Длительность — до 4.5 с, без петли; при
«меньше движения» набор классов не ставит. Мотив рассказывает о деле (пар над чашкой, мука на
доску, вишня на торт), а не «выезжает снизу».

## Детали под сайт, а не шаблоном

- **Каждый раздел — свой голос.** Токены раздела — на его классе: шрифт надписи-логотипа
  (`--dk-logo-font`), его же подхватывает бледное слово раздела; свой знак (SVG на 24) и свой мотив.
  Что донор делает разным (четыре заведения — четыре шрифта, у одного рукописный), не приводить к
  одному виду: разнообразие донора — это его язык, и при проверке глазами разные надписи — не
  небрежность («Эпицентр», 29.09: их привели к одному виду — владелец потребовал разнообразие обратно).
- **Шрифты** — Google Fonts с кириллицей, проверенной отрисовкой:
  `node ~/.claude/skills/design-reference/scripts/cyrillic-check.mjs "Шрифт" "Другой:600"`
  (запуск из папки с puppeteer-core — `~/.claude/site-rework`). Для надписей-логотипов — `&text=`
  со всеми буквами названий, бледных слов и печатей **в обоих регистрах** (капс через
  `text-transform` рисует заглавные): 2–12 КБ на шрифт. Добавили слово — добавьте буквы, иначе их
  нарисует запасной шрифт. «Ё» в капсе — проверить глазами.
- **Фон с характером** — не всё сразу: на раздел один-два слоя (бледное слово, россыпь, фактура
  `templates/grain.css`). Бледное слово — 5–9 % (фон, не текст: контраст текста над ним не меняется),
  рисунки россыпи — 10–16 %.
- **Предмет за краем** — вырезка из снимка дела (`media.mjs`, прозрачный фон) или свой рисунок; на
  телефоне проверить, что не лёг на заголовок.
- **Движение** — сначала донорское по протоколу `motion.mjs` (`reference/motion.md`), сверху 1–2 идеи
  банка (`ideas.mjs pick --run <прогон> --kind motion --for "<о чём сайт>"`) и мотивы разделов.
  Не на каждый блок: одно-два движения на экран, по смыслу.

## Правила своих SVG-рисунков линией

1. **Из мира этого дела, а не донора**: предметы, инструменты, сырьё, место (у пекарни — каравай,
   колос, скалка; у барбера — бритва, помазок). Материалы донора не копировать — только язык.
2. **Один вес линии** на весь набор; цвет — `currentColor` (`stroke="currentColor"` или ничего:
   набор ставит его сам); **без заливок** (`fill="none"`); скруглённые концы и углы.
3. **`pathLength="1"` у каждого контура** — иначе прорисовка даёт пунктир.
4. **`vector-effect="non-scaling-stroke"` вместе с `pathLength` не ставить.** Проверено 30.09.2026 в
   Chrome 154 и Firefox 157: длина штриха считается в поле рисунка, а кладётся в пикселях экрана, и
   рисунок крупнее поля режется на куски — «полностью нарисованный» с разрывами, «спрятанный» с
   обрывками. Одну толщину на экране держит набор: `--dk-line` и пересчёт под настоящий размер
   (`--dk-s` в CSS, ResizeObserver в скрипте). Статичному значку, который никогда не рисуется линией,
   `vector-effect` не вредит, но и не нужен.
5. **Видимы без JS**: обычный вид рисунка — конечный; прячет его до входа в экран только скрипт.
6. **Декор**: `aria-hidden="true"` и `focusable="false"` у каждого `<svg>`; клики не ловят
   (`pointer-events: none` у `.dk-draw`).
7. **Простые контуры, не клипарт**: поле 64×64 (знаки надписей — 24×24), отступ 4–6 от края;
   2–7 контуров на рисунок, без деталей мельче 2 единиц поля, без теней, штриховки и объёма; не
   значки из готовых наборов. Узнаётся на 40 px и не пустеет на 200 px.
8. **Проверка**: каталог рисунков на странице (как в `demo.html`) — глазами на 64 и 200 px; в консоли
   набор предупреждает `[decor-kit] рисунок #id: … нет pathLength` и `… vector-effect` (спрайт в
   странице; отдельный файл скрипт прочесть не может).


  остаются только рисунки `data-dk-draw="scroll"` — они привязаны к прокрутке;
- 320 px — «переполнение: OK»: слои и россыпь обрезаны своим блоком, предмет за краем — только вверх
  и вниз;
- «меньше движения»: `assert` true, на полном снимке всё в конечном виде, автосмена стоит («Дальше»);
- снимки первого экрана и середины страницы открыть глазами: надписи-логотипы своими шрифтами, у
  разделов разные мотивы, печать заполнена по кругу, россыпь не лежит на тексте;
- браузер владельца — Firefox (`--browser firefox`).

## JS

```js
import { init, scan, play, registerMotif, logo, draw, autoplay, finish, config } from '/assets/decor-kit/decor-kit.js';
```

| вызов | что делает |
|---|---|
| `scan(root)` | разобрать разметку внутри `root`; то, что страница дорисует позже, набор подхватывает сам (MutationObserver) |
| `play(el)` | сыграть мотив заново |
| `registerMotif(имя, build)` | мотив, который строит скрипт: `build(el, { rng, hash })` |
| `logo('Выпечка', { sign: 'sign-pastry', row: true, cls: 't-pastry' })` | разметка надписи-логотипа строкой |
| `draw('loaf', { size: 96, mode: 'in' })` | разметка рисунка строкой |
| `autoplay.go / pause / stop` | управление автосменой |
| `finish()` | всё в конечный вид сразу |
| `config` | `sprite` (адрес спрайта без `#id`), `locale` (`ru-RU`), `wideMin` (900 — параллакс с этой ширины) |

Для обычных (не модульных) скриптов то же — `window.decorKit`.

## Чем отличается от исходника «Эпицентра»

- Приставка `dk-` и атрибуты `data-dk-*`: не пересекаются со старыми `data-reveal` на сайтах.
- Рисунков, шрифтов, наборов по заведениям и мотивов в наборе нет — у каждого сайта свои; набор не
  грузит шрифты сам.
- Прорисовка без `vector-effect`; спрятанное состояние — `1 1.01` и сдвиг 1.005 (с `1` и 1 Chrome
  оставлял точку от круглого конца).
- Шторка фото действительно идёт: в исходнике правило `.md-on img { transition: transform … }` перебивало
  `transition: clip-path` у фото — прямого ребёнка обёртки, и шторка прыгала в конец, играл только отъезд
  (найдено 30.09 замером `getAnimations()`: через 300 мс шёл один transform). Здесь у img и video оба перехода.
- Табло пишет число через `toLocaleString` и после ленты возвращает обычный текст.
- Цитата по словам на первом экране не гаснет.
- Автосмена стала самостоятельной: заливка — таймер, пауза вне экрана и на скрытой вкладке, кнопка
  «Пауза», слайды без JS видны все.
- Мотивы — крючок (`.dk-set` / `.dk-play`, `registerMotif`), а не четыре зашитых мотива.
- Печать может быть вписана разметкой (видно без JS).
- У низа страницы досрабатывает то, что ждёт входа в экран, но уже не поднимется.
- Плашка акцента за заголовком, большая кавычка и линия «листай» — детали донора «Эпицентра»: они
  делаются своими средствами по донору конкретного сайта, в общий набор не вошли.
