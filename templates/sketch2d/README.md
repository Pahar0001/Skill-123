# sketch2d — свои рисунки от руки для фона

Приём «в фон встроены рисунки в тему»: бледные наброски блюд и зелени у ресторана, инструмента у
мастерской, растений у магазина семян. Чужие картинки и файлы донора не берём — рисуем сами: фигуры
собираются кодом и проходят через «рваную линию» (`svg3d.mjs rough`, Rough.js): контур дрожит, заливка
ложится штриховкой, как в полевом определителе. Вынесено из боевого прогона «Зелёный уголок»
(01.10.2026): образец владельца — mamuka.rest, слова — «2D красивые в тему картинки встроены, это
тоже надо уметь».

| Файл | Что в нём |
|---|---|
| `sketch-kit.mjs` | заготовки фигур (`leaf`, `ellipse`, `box`, `curve`, `line`), расстановка `place`, путь `P`, лист `svg`, сборка `build` |
| `botanical.mjs` | образец: клевер, колос, горчица, пчела, росток — пример, а не заготовка под любой сайт |

## Порядок

1. **Что рисовать** — из мира дела, 4–6 предметов; список — в `analysis.md`, раздел «Детали для красоты».
   У образца снять приём, а не картинки: `bgdecor.mjs <донор>` покажет, где они стоят, какого размера и
   насколько бледные.
2. **Нарисовать**: скопировать папку в прогон (`<прогон>/sketch2d`), написать свой файл по образцу
   `botanical.mjs` — каждая картинка — функция, которая возвращает `svg(ширина, высота, [пути])`.
   ```sh
   node <прогон>/sketch2d/<свой>.mjs --out <папка сайта>/img/sketch --ink "#2F6B2A" --sheet <прогон>/look/sketch2d.png
   ```
3. **Посмотреть лист** глазами. Не похоже — править фигуры и углы; обычно хватает двух-трёх заходов.
   Дрожание линии — `roughness` (1.15), шаг штриховки — `gap` (5.5) в `build()`.
4. **Поставить на сайт** бледно и за содержимым:
   ```html
   <img class="sk" src="/img/sketch/clover.svg" alt="" width="400" height="500" loading="lazy" decoding="async">
   ```
   ```css
   .sk{opacity:.42;pointer-events:none;user-select:none}          /* тушь на бумаге; на тёмном фоне — светлая тушь */
   ```
   Места: справа от заголовка секции, где колонка пуста; под заголовком в боковой колонке; в пустом
   месте под фото товара. Не под абзацами текста. На телефоне — только там, где рисунок стоит в потоке.

## Правила

- **Преобразований SVG в исходнике нет** (`transform`): «рваная линия» работает с готовыми координатами —
  поворот и сдвиг делает `place(фигура, x, y, угол)`.
- **Заливка = цвет штриховки.** `fill: 'none'` — только контур. Тушь контура — `ink` на всё сразу.
- **Тот же `seed` — тот же файл побайтно**: рисунок можно пересобрать и получить то же самое.
- **Вес** — 5–16 КБ на рисунок после `optimize`; в спрайт не собирать, грузить лениво.
- Движение, если нужно, — прорисовка линией из `templates/decor-kit` (`.dk-draw`), а не здесь.

## Чем проверить

`runtime.mjs <url> --scroll` — рисунок не перекрывает текст и не торчит за край; `a11y.mjs` — у картинки
пустой `alt`, контраст текста рядом не упал; `bgdecor.mjs compare <донор.json> <наш url>` — приём,
который есть у донора, есть и у нас.
