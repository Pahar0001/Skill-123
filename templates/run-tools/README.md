# run-tools — разовые инструменты прогона

Заготовки, которые в боевых прогонах каждый раз писались заново в `<прогон>/tmp/`. Вынесены из прогона
«Зелёный уголок» (01.10.2026). Это **не скрипты навыка**: у них нет самопроверок и протоколов, вердикты
для журнала они не дают. Их задача — быстро посмотреть глазами и подготовить картинки; числа и
доказательства по-прежнему снимают `runtime.mjs`, `shots.mjs`, `a11y.mjs`, `perf.mjs`.

Порядок: скопировать папку в прогон и запускать оттуда —

```sh
cp -r ~/.claude/skills/site-rework/templates/run-tools <прогон>/tools
cd <прогон>/tools
export RUN_DIR=<прогон> LOOK_BASE=http://localhost:3100        # папка прогона и адрес стенда
```

Пути страниц давать **без ведущей косой** (`catalog/x`, главная — `home`): Git Bash подменяет `/catalog`
на путь к своей папке.

| Файл | Зачем | Запуск |
|---|---|---|
| `look.mjs` | вся страница на 1440 и 390 после правки: высота, переполнение, число h1, ошибки консоли | `node look.mjs r1 home catalog product/x [--only m] [--cookie "a=b"]` |

## Что из боевого прогона стоит помнить

- **Стенд — отдельным процессом.** Фоновая команда гаснет вместе с сессией (за вечер — дважды). В PowerShell:
  `Start-Process node -ArgumentList '--watch','server.js' -WorkingDirectory <папка> -WindowStyle Hidden
  -RedirectStandardOutput <прогон>\server.log`; после сводки или перезапуска первым делом проверить порт.
- **Скорость «до» мерить до правок и через сжатие.** Локальный сервер без сжатия завышал первую отрисовку
  вдвое (стили 64 КБ вместо 16). Если «до» не снято — `git archive HEAD:<папка>` в `<прогон>/before-app`, другой
  порт, **копия** базы (`VACUUM INTO`, а не копирование файла: при журнале WAL копия вышла пустой), и сверить,
  что страница отдаёт те же товары, прежде чем сравнивать числа. Каталог `node_modules`, подключённый
  соединением (junction), перед удалением папки снимать `cmd /c rmdir`, иначе `rm -rf` сотрёт модули проекта.
- **Состояния — сценарием.** Форма с пустыми полями (снять `required` — увидеть ошибки сервера), меню и Esc,
  подсказки поиска на телефоне (они живут в другом поле, чем на широком экране), корзина с куками покупателя.
  Отправка форм пишет в базу стенда — `states.mjs` по умолчанию работает только с localhost.
- **Перекрытия глазами не ловятся.** Подпись на фото лежала под карточкой внахлёст: на листах не видно, `a11y`
  показал контраст 1.05. `contrast-at.mjs` скажет то же числом — худшие 10 % при хорошей медиане.
- **Одно понятие — одно слово.** `strings.mjs --grep` по корням («заказ», «заявк», «доставк», «перевоз»)
  показал девять страниц, где одно и то же называлось по-разному.
- **Чужой текст — только набор.** Статьи и описания заказчика из базы правит `typo()` при выводе; слова и
  смысл — списком «было → стало» владельцу.

Чего здесь нет нарочно: проверок с вердиктом (они в `scripts/`), генератора фактуры (`surface-tile.mjs`),
набросков (`templates/sketch2d/`) и рендера предметов (`scripts/blender.mjs`, `templates/blender/`).
