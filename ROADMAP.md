## 1. Кириллица к латинским шрифтам (`fonts.mjs cyrillize`) — записано 06.10.2026

Стек владельца: Claude → концепция гарнитуры → дизайн букв в SVG → Inkscape → проверка и корректировка →
FontForge → OTF / TTF / WOFF2 → сайт.

**Можно только там, где лицензия разрешает изменения:**

| шрифт | дорисовать кириллицу |
|---|---|
| SIL OFL 1.1 без кириллицы (Bebas Neue и ещё ~1600 семейств Google) | да; у шрифта с зарезервированным именем (Reserved Font Name) — новое имя; лицензия остаётся OFL, текст рядом с файлами |
| Fontshare (ITF Free Font License 2.0) | **нет**: §05 запрещает производные без письменного согласия ITF — сначала письмо в ITF |
| своя гарнитура с нуля | да, она наша |

**Как устроить:**
1. Проверка лицензии до работы (`sources.json`, `license.noModify` → отказ).
2. Буквы, совпадающие с латиницей (А В Е К М Н О Р С Т Х, а е о р с у х и др.), — ссылками на латинские глифы;
   И, Я — зеркало N, R; Г, П, Ш, Щ, Ц, Ы, Ь, Ъ — из ножек и перекладин готовых букв; новые (Ж Д Ф Л Б З Э Ю, Й Ё —
   надстрочные) — рисунок в SVG по меркам шрифта (высота прописных, x, толщина штриха — числа `fonts.mjs measure`).
3. FontForge из Python без окна: импорт SVG, чистка контуров (наложения, направление, экстремумы), метрики и
   боковые поля по образцу латинских, кернинг пар с кириллицей, сборка OTF/TTF/WOFF2. Inkscape — по желанию,
   для ручной правки контуров (через командную строку тоже работает).
4. Приёмка — лист `fonts.mjs sheet` (кириллица рядом с латиницей, капс с Й/Ё при 0,9 и 1,0) и глаза владельца;
   `fonts.mjs measure` новой кириллицы против латиницы того же файла — числа не должны расходиться.
5. Начать с заголовочного шрифта капсом (логотипы, крупные заголовки); наборный шрифт для текста — позже,
   там нужен кернинг и больше проверок.

**Нужно поставить (с согласия владельца):** `brew install fontforge`, `pip install fonttools` (в venv скилла);
Inkscape — `brew install --cask inkscape`, если понадобится ручная правка.
